# Smart-Acoustofluidic-Nanodetector

#PROJECT OVERVIEW
Smart Acoustofluidic Nanodetector (SAN-X1) is an interactive 3D Web SPA demonstrating next-generation nanobiological particle (Exosome) isolation from blood using Standing Bulk Acoustic Waves (BAW) and Real-time AI Vision for Precision Medicine diagnostics.

#KEY FEATURES & HIGHLIGHTS
- 3D Autonomous Hero Banner: Smooth, continuous 3D rotating microfluidic chip background powered by Three.js.
- 3D Acoustofluidic Physics Engine:
  * Transparent 3D Glass Channel with 3-Outlet fluidic separation architecture.
  * Pulsing 3D Standing Acoustic Wave interference planes & central pressure nodal line (Y=0).
  * Dynamic Particle Physics: Large Cells (Cyan) acoustic-focused to center line; Exosomes (Pink) flowing to side outlets.
- Real-time AI Vision System: Holographic AI Bounding Box target acquisition & classification at 60 FPS.
- Telemetry Dashboard & Controls: Interactive flow velocity & acoustic power sliders with real-time stats dashboard.
- Academic LaTeX Math Engine: Publication-grade LaTeX equations rendered via KaTeX (f = c / 2w = 3.25 MHz).
